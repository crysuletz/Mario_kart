## Partie de Cristiana : la course et les menus

- Menus : menu principal, choix du circuit (Campagne, Canyon, Glace), écran de victoire
- RaceManager : compte les checkpoints dans l'ordre, les tours et le gagnant
- Détection dans GameModel : un checkpoint ou la ligne d'arrivée ne compte que si la voiture la traverse dans le sens du circuit
- Affichage pendant la course : tours et checkpoints de chaque joueur en haut de l'écran
